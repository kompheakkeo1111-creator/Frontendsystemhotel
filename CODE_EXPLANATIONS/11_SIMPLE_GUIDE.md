# SIMPLE GUIDE FOR BEGINNERS
## Easy to Understand

---

## What is This System?

This is a **Hotel Management System** for a hotel called "Arizu Arimato" in Siem Reap, Cambodia.

It has two parts:
1. **Frontend** - Website for guests to book rooms
2. **Backend** - Admin panel for staff to manage everything

---

## How to Use

### For Guests (Frontend)

1. **Visit Website**
   - Go to: https://kompheakkeo1111-creator.github.io/Frontendsystemhotel/

2. **Browse Rooms**
   - Click "Rooms" in menu
   - See room types and prices

3. **Book a Room**
   - Select check-in date
   - Select check-out date
   - Click "Search"
   - Click "Book Now" on a room
   - Fill in your details
   - Click "Submit"

4. **Contact Hotel**
   - Click "Contact" in menu
   - Fill in form
   - Click "Send Message"

---

### For Staff (Backend)

1. **Login**
   - Go to: https://arizu-arimato.free.nf/backend/index.php
   - Username: `admin`
   - Password: `admin123`

2. **Dashboard**
   - See statistics (rooms, guests, revenue)
   - See charts (revenue, room types)
   - See room status board

3. **Manage Rooms**
   - Go to "Rooms" page
   - Add new room
   - Edit room details
   - Delete room

4. **Manage Guests**
   - Go to "Guests" page
   - Add new guest
   - Edit guest details
   - View guest history

5. **Manage Reservations**
   - Go to "Reservations" page
   - Add new reservation
   - Edit reservation
   - Cancel reservation

6. **Check-In Guests**
   - Go to "Check-in" page
   - See reservations ready for check-in
   - Click "Check In" button
   - Or use "Walk-in Check-in" for walk-in guests

7. **Check-Out Guests**
   - Go to "Check-out" page
   - See active stays
   - Add extra charges (if any)
   - Select payment method
   - Click "Payment & Check-out"

8. **View Reports**
   - Go to "Reports" page
   - See revenue charts
   - See occupancy rates
   - Export to CSV

## Common Tasks

### How to Add a Room Type
1. Login to admin
2. Go to "Room Types"
3. Click "Add Room Type"
4. Enter name, price, capacity
5. Click Save

### How to Add a Room
1. Login to admin
2. Go to "Rooms"
3. Click "Add Room"
4. Enter room number, select type
5. Click Save

### How to Create a Reservation
1. Login to admin
2. Go to "Reservations"
3. Click "Add Reservation"
4. Select guest and room
5. Enter dates
6. Click Save

### How to Check In a Guest
1. Login to admin
2. Go to "Check-in"
3. Find the reservation
4. Click "Check In"

### How to Check Out a Guest
1. Login to admin
2. Go to "Check-out"
2. Find the active stay
3. Add any extra charges
4. Select payment method
5. Click "Payment & Check-out"

### How to Backup Database
1. Login to admin
2. Go to "Settings"
3. Click "Backup Database"
4. Download the .sql file
